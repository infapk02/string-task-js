# JavaScript String Practice

This repository contains five JavaScript practice tasks focused on string manipulation, character counting, vowel checking, replacing characters, and capitalizing words.

## 📚 Tasks Overview

### Task 1: Count the Letter `a`

- Count how many times the lowercase letter `a` appears in a string.
- Use a `for...in` loop to iterate through the string.
- Use a counter variable to track the number of occurrences.

### Task 2: Count the Letters `a` and `A`

- Count both lowercase `a` and uppercase `A` in a string.
- Use the logical OR (`||`) operator to check both conditions.
- Increment the counter whenever either condition is true.

### Task 3: Check All Vowels

- Check whether a string contains all five vowels: `a`, `e`, `i`, `o`, and `u`.
- Use the `includes()` method to check each vowel.
- Use the logical AND (`&&`) operator to ensure all vowels are present.

### Task 4: Replace Characters

- Replace every lowercase `x` with `y`.
- Replace every uppercase `X` with `Y`.
- Use the `replaceAll()` method to replace all occurrences of each character.

### Task 5: Capitalize the First Letter of Every Word

- Capitalize the first letter of each word in a string.
- Use `split()` to convert the string into an array of words.
- Use `charAt()`, `toUpperCase()`, and `slice()` to capitalize each word.
- Use `join()` to convert the array back into a string.

## 🛠️ Technologies Used

- JavaScript (ES6+)

- Logical Operators (`&&`, `||`)
- Array Methods

1. Clone this repository.
2. Open the project folder in VS Code.
3. Open the JavaScript file containing the tasks.
4. Run the file using Node.js:

   ```bash
   node filename.js
   ```

   Replace `filename.js` with your actual JavaScript filename.
